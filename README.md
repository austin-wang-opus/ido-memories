# Ido — Memories prototype

A static prototype for personalized brick keepsakes made from meaningful photographs.

Latest concept: [Memories website](https://austin-wang-opus.github.io/ido-memories/memories/).

The original concept is retained at the site root for comparison. Lifestyle images are AI-generated illustrations, not verified supplier samples. Prices and brick palettes are illustrative; ordering and payments are not enabled. Uploaded photos are processed locally in the visitor's browser.

## Hosting

GitHub Pages publishes the root of the `main` branch. This repository contains only deployable website files, not the founder's local documents or development history.

To update, copy the latest HTML, CSS, JavaScript and JPG assets from the local project's `dist/` folder into their matching paths here, review the changes, then commit and push to `main`. Do not copy working documents, secrets, or prompt notes.
